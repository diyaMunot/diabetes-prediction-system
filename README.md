# 🩺 Diabetes Prediction System

## About the Project

This project uses Machine Learning to predict whether a patient is likely to have diabetes based on medical attributes such as glucose level, BMI, age, insulin level, and blood pressure.

The application is built using Streamlit and provides an interactive interface for prediction.

## Features

- Diabetes Risk Prediction
- Interactive User Interface
- Machine Learning Model
- Real-time Predictions
- Data Analysis

## Tools Used

- Python
- Streamlit
- Scikit-Learn
- Pandas
- NumPy

## Dataset

Pima Indians Diabetes Dataset
